# Кровь и Листва — хроники четырёх земель

Небольшой 3D action-RPG прототип на Three.js. Один большой мир, четыре земли,
три играбельные фракции, рубка, отрубленные конечности, протезы, коляска,
корованы, торговля и сохранения.

**Живая версия:** <https://blood-and-leaves.onrender.com>

## Запуск

Нужен только Python 3 — Node.js и сборка не требуются. Three.js уже лежит в
`vendor/three.module.js`.

```powershell
cd C:\OpenCode\2year
python serve.py 8081
```

Откройте <http://localhost:8081>.

Важно: запускайте именно через `serve.py`, а не через `python -m http.server`.
На Windows реестр иногда отдаёт `.js` как `text/plain`, из-за чего браузер
отказывается загружать ES-модули. `serve.py` принудительно выставляет
правильные MIME-типы.

## Запуск в Docker

Игра не требует сборки и зависимостей — в контейнер копируются только
статические файлы и `serve.py`.

```bash
docker build -t blood-and-leaves .
docker run --rm -p 8080:10000 blood-and-leaves
```

Откройте <http://localhost:8080>. Внутри контейнера сервер слушает
`0.0.0.0:10000`; порт можно переопределить переменной `PORT`.

## Публикация на Render

В репозитории есть `Dockerfile` и `render.yaml` (Blueprint). Render собирает
образ удалённо и сам передаёт переменную `PORT`.

1. Запушьте репозиторий на GitHub.
2. В Render выберите **New → Blueprint** и укажите репозиторий.
3. Render создаст web service `blood-and-leaves` на бесплатном плане в
   регионе Frankfurt.

Либо создайте **New → Web Service**, выберите runtime **Docker** и укажите
`Dockerfile` в корне репозитория.

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` | движение |
| `Shift` | бег |
| `Пробел` | прыжок |
| ЛКМ | удар |
| ПКМ | блок |
| `E` | взаимодействие / диалог / лут |
| `H` | перевязать рану |
| `1` | выпить зелье |
| `2` | сесть в коляску / встать |
| `M` | карта мира |
| `I` | инвентарь |
| `T` | приказы войску (только за Тёмного Владыку) |
| `Esc` | пауза, сохранения, выход в меню |
| `F5` | быстрое сохранение |
| `F9` | быстрая загрузка |

Мышь захватывается кликом по игровому полю. `Esc` отпускает курсор.

## Фракции

- **Эльфы** — густой лес, деревянные дома, Древо Совета. Защищайте чащу от
  имперских солдат и слуг Владыки, грабьте корованы.
- **Страж дворца** — служите командиру Дорну: патрули, оборона ворот, набеги
  на эльфийский лагерь и охота на шпионов.
- **Тёмный Владыка** — собственный отряд, приказы через `T`: штурм дворца,
  набег на лес, оборона старого форта, дань с корована.

## Что есть в игре

- Четыре зоны: Долина людей, Имперские земли, Лес эльфов, Горный форт.
- Лес с LOD: вдали деревья рисуются как билборды, рядом превращаются в
  настоящие 3D-модели.
- 3D-враги, трупы, кровь, отрубленные руки/ноги/головы.
- Травмы: потеря руки/ноги/глаза, кровотечение, протезы, коляска, лечение.
- Корованы, которые можно ограбить.
- Магазины торговца, кузнеца и лекаря.
- Квесты фракций, награды, уровни и опыт.
- Сохранения в `localStorage`: три ручных слота и автосохранение.

## Сохранения

Игра хранит данные в браузере:

- `bloodleaves_slot_1`, `bloodleaves_slot_2`, `bloodleaves_slot_3` — ручные слоты;
- `bloodleaves_auto` — автосохранение после важных событий;
- `bloodleaves_last` — последнее использованное сохранение.

Слоты доступны в меню паузы (`Esc`), там же кнопки сохранения и загрузки.

## Структура проекта

```text
index.html          разметка интерфейса
styles.css          стили HUD, меню, диалогов, карты и магазинов
serve.py            локальный сервер с правильными MIME-типами
vendor/three.module.js
src/main.js         запуск, игровой цикл, взаимодействия, магазины, сохранения
src/world.js        мир, зоны, дворец, эльфийская деревня, форт, лес и LOD
src/player.js       контроллер игрока, бой, травмы, протезы, коляска
src/npcs.js         NPC, фракции, отряды, корованы, трупы и возрождение
src/quests.js       цепочки заданий и приказы Владыки
src/humanoid.js     модели гуманоидов и отстёгиваемые конечности
src/effects.js      кровь, искры, декали, обломки и цифры урона
src/ui.js           меню, HUD, карта, диалоги, магазин, инвентарь, сохранения
src/textures.js     процедурные canvas-текстуры
src/audio.js        процедурный звук
```

## Технические заметки

- Three.js r160, ES-модули, без сборщика и без внешних ассетов.
- Все текстуры и звуки генерируются процедурно.
- Мир 900×900 м; поселения выровнены по плато.
- Лес: около 1700 деревьев, билборды вдалеке и лениво создаваемые 3D-группы
  рядом с игроком.
- Сохранение сериализует игрока, инвентарь, травмы, снаряжение и активный
  квест; при загрузке мир и отряды восстанавливаются заново.
